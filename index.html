Introducción al Desarrollo Web

El desarrollo web es el proceso de creación de páginas y sitios web que se visualizan a través de un navegador como Chrome, Firefox o Edge. Para crear una página web básica se utilizan principalmente dos lenguajes: HTML y CSS.

HTML se encarga de la estructura del contenido, mientras que CSS se encarga del diseño visual, la presentación y la organización del contenido en la pantalla.

HTML: Lenguaje de Estructura

HTML (HyperText Markup Language) es un lenguaje de marcado que se utiliza para estructurar el contenido de una página web. No es un lenguaje de programación, sino un lenguaje que usa etiquetas para indicar al navegador cómo debe organizar la información.

Con HTML se pueden crear títulos, párrafos, listas, enlaces, imágenes y dividir la página en secciones claramente definidas.

¿Cómo funciona HTML?

HTML funciona mediante etiquetas que generalmente tienen una etiqueta de apertura y una de cierre. El contenido se coloca entre ambas etiquetas. 

<p>Este es un párrafo</p>

Estructura básica de una página HTML

<!DOCTYPE html>
<html>
<head>
    <title>Mi página web</title>
</head>
<body>
    Contenido visible
</body>
</html>

Esta estructura es obligatoria y le permite al navegador interpretar correctamente el contenido de la página.

Etiquetas Semánticas de HTML

Las etiquetas semánticas permiten que el contenido tenga un significado claro según su función. Estas etiquetas mejoran la organización del código y hacen la página más accesible.

  • <header>: encabezado principal
  • <nav>: menú de navegación
  • <main>: contenido principal
  • <section>: secciones de contenido
  • <footer>: pie de página

CSS: Lenguaje de Diseño

CSS (Cascading Style Sheets) es el lenguaje que se utiliza para dar estilo y diseño a una página web. Con CSS se pueden modificar colores, tamaños, tipografías, márgenes y la posición de los elementos.

CSS funciona relacionando una propiedad con un valor específico. Estas reglas se aplican a los elementos HTML.

Ejemplo de una regla CSS

p {
    color: green;
    font-size: 16px;
}

En este ejemplo, el texto de los párrafos se muestra en color verde y con un tamaño de letra definido.

Modelo de Cajas y Flexbox

En CSS, todos los elementos HTML se consideran cajas. Flexbox es un modelo de diseño que permite organizar estas cajas de manera flexible y sencilla, adaptándose al tamaño de la pantalla.

Para usar Flexbox, primero se debe definir un contenedor al cual se le aplica la propiedad display: flex.

Estructura HTML para Flexbox

<div class="contenedor-flex">
    <div class="caja">Caja 1</div>
    <div class="caja">Caja 2</div>
    <div class="caja">Caja 3</div>
</div>

Código CSS usado en Flexbox

.contenedor-flex {
    display: flex;
    gap: 15px;
    flex-wrap: wrap;
}

.caja {
    background-color: #4CAF50;
    color: white;
    padding: 20px;
    flex: 1;
    text-align: center;
}

El contenedor controla la posición de las cajas, mientras que cada caja se adapta automáticamente al espacio disponible.

Gracias a Flexbox, las cajas se muestran en una fila cuando hay espacio suficiente. En pantallas pequeñas, las cajas bajan automáticamente, haciendo que el diseño sea responsivo.
